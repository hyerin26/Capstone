# Magma explicit-object attention 실험 결과

10개 카테고리의 250개 pair를 좌우 교체해 총 500개 장면을 평가했습니다. 전체 추론과 attention 파일 무결성 검사를 완료했습니다.

## 핵심 결과

- 텍스트 선택 정답률: **74.2% (371/500)**. 카테고리를 동일하게 가중한 평균은 **77.4%**입니다.
- 형식에 맞지 않는 응답: **0개**. 오른쪽 선택은 **363/500 (72.6%)**입니다.
- 정답이 왼쪽인 경우 **51.6% (129/250)**, 오른쪽인 경우 **96.8% (242/250)**를 맞혔습니다.
- 좌우 두 배치를 모두 맞힌 pair는 **129/250 (51.6%)**입니다. 선택 방향이 swap에 따라 바뀐 비율은 **54.8%**이며, 이 지표에는 두 배치 모두 틀린 pair도 포함됩니다.

## 해석할 때 주의할 점

이 실험은 로봇 카메라 이미지와 지시문을 주고 LEFT/RIGHT로 응답하게 한 정적 선택 실험입니다. 실제 로봇 행동 성공률이나 박스 검출 정확도가 아닙니다.
Counting과 Symmetry의 Explicit object 지시문은 색상 단서로 타일을 고릅니다. 이 두 카테고리의 100%를 수 세기 또는 대칭 추론 능력으로 해석하면 안 됩니다. 각 10개 pair라는 작은 표본에서 관측한 결과입니다.
Attention은 마지막 프롬프트 위치에서 이미지 특징으로 향하는 가중치입니다. 32개 레이어와 32개 head를 저장했고 공간 격자는 16×32입니다. 마스크는 사진 속 물체가 아니라 타일 전체이며, ConvNeXt의 겹치는 receptive field 때문에 픽셀 단위 위치 해석은 근사입니다.
정답 타일의 평균 attention 밀도가 오답 타일보다 높았지만, 이것만으로 해당 물체를 정확히 인식하거나 인과적으로 사용했다고 결론 내릴 수 없습니다. 일부 카테고리는 차이가 작습니다.
가림 실험은 대문자 LEFT/RIGHT 두 토큰의 점수 차이를 사용합니다. 이 후보 순위 정확도는 57.4%로 자유 생성 정확도와 다릅니다. Left/Right 등 다른 표기와 생성 경로를 합산하지 않았으므로, 가림 그래프를 전체 응답 확률의 변화로 해석하지 마세요. 회색 가림 및 흩어진 배경 대조군의 형태 차이도 제한점입니다.
Pair bootstrap 신뢰구간은 2,000회 재표집 결과입니다. 전부 맞힌 작은 표본에서 구간이 100–100%로 퇴화하더라도 모집단 성능이 확실히 100%라는 뜻은 아닙니다.

## 다음 실험 제안

우선 위치 편향을 분리하는 실험이 필요합니다. 같은 두 타일을 동일한 크기로 잘라 배치한 입력과 원래 로봇 카메라 입력을 비교하면, 좌우 선호와 원근·크기·배경 영향을 구분하는 데 도움이 됩니다. 현재 결과만으로 편향의 원인이 모델 자체인지 화면 구성인지 단정할 수 없습니다.
다음으로 LEFT/RIGHT, Left/Right, left/right 등의 응답 표기를 함께 평가하거나 동일한 후보 문장의 전체 확률을 비교해 점수 정의에 따른 영향을 점검하는 것이 좋습니다.
